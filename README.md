## Projects

### 1. On-Time Delivery Rate (`on_time_rate.py`)

A Python exercise that evaluates order delivery performance by comparing expected and actual delivery times.

The program:
- Classifies orders as early, on time, or late.
- Counts the number of orders in each category.
- Calculates the percentage of orders delivered on time or early.

**Python concepts practiced:**
- Lists and nested lists
- For loops
- Conditional statements (`if`, `elif`, `else`)
